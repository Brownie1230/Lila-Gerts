# Lila Gerts — правила работы в репозитории

Сайт мастерской: свечи и гипсовые фигурки ручной работы. Одна страница, статика,
без сборки. Правки идут прямо в `index.html`, `assets/css/*`, `assets/js/app.js`.

---

## 1. Скиллы применяются всегда

В `.claude/skills/` лежит 184 скилла. **Их применение обязательно для любой задачи
в этом репозитории** — не только для вёрстки. Перед тем как написать первую строку
кода или текста, нужно открыть и прочитать подходящие скиллы, а не работать по памяти.

Порядок действий для любой задачи:

1. **Выбрать скиллы.** Посмотреть `.claude/SKILLS.md` — это карта: что есть и о чём.
   Взять те, что относятся к задаче. Минимум два: один профильный, один проверочный.
2. **Прочитать их целиком**, включая файлы в `references/`, `templates/`, `scripts/`
   рядом со `SKILL.md`. Скилл, который не прочитан, не считается применённым.
3. **Объявить design read** до начала работы, как требует `taste-skill`: одной строкой —
   что за страница, для кого, на каком визуальном языке.
4. **Сделать работу** по тому, что сказано в скиллах.
5. **Проверить себя** по проверочным скиллам перед коммитом (см. таблицу ниже).

Если задача выглядит так, что скиллы к ней не подходят, — это почти всегда означает,
что скилл не найден, а не что его нет. Искать по `.claude/SKILLS.md`, затем
`grep -ril "<тема>" .claude/skills/*/SKILL.md`.

### Проверочные скиллы перед коммитом

Прогнать работу через них всегда, без исключений:

- `impeccable` — финальная вычитка качества.
- `design-qa-checklist` — чек-лист сдачи.
- `critique-typography`, `critique-color`, `critique-composition`,
  `critique-visual-hierarchy` — визуальная критика собственной работы.
- `steve-jobs-design-review` — «что здесь лишнее».
- `accessibility-audit` — контраст, фокус, клавиатура, `prefers-reduced-motion`.

## 2. Что в этом проекте нельзя

Это требования заказчицы и ограничения проекта. Они сильнее любого скилла.

- **«Ароматы», не «отдушки».** Заказчица поправила отдельно. В текстах только «ароматы».
- **Материал — гипс.** Не керамика, не воск, не бетон.
- **Палитра — крем и вишня** из `assets/css/tokens.css`. Чипы `--c-*` взяты
  с пантонных листов заказчицы, менять их значения нельзя. Семантические токены
  (`--bg`, `--ink`, `--accent`) менять можно.
- **Цвет у заказчицы всегда парой.** Сочетания в форме заказа (`.duos`) — её список,
  две краски на чип. Не сводить к одному тону.
- **Логотип: «Лила» рукописным над «GERTS» капителью.** Файл со шрифтом заказчица
  пришлёт отдельно; до этого Grand Hotel + Cormorant Garamond — это замена, а не выбор.
  Когда придёт файл, менять в одном месте: `assets/css/fonts.css` и `--font-script`.
- **Сборки нет и не будет.** Без npm, без бандлера, без внешних CDN. Шрифты, стили,
  скрипты и картинки лежат рядом, страница открывается с файла и без интернета.
- **Без фреймворков.** Нативные CSS и JS. Скиллы, написанные под React/Tailwind/Next,
  применять по смыслу (принципы), а не по букве (код).
- **Приватность.** Контакты мастерской в тексте — настоящие, их не выдумывать и
  не подменять. Раздел «Обработка данных» описывает фактическую работу формы.

## 3. Качество, ниже которого не опускаемся

Проверять руками на каждой правке:

- Мобильный от 360px: без горизонтальной прокрутки, всё читается.
- Фокус с клавиатуры видно на каждом интерактивном элементе.
- `prefers-reduced-motion: reduce` выключает всю несущественную анимацию.
- Контраст текста — не ниже 4.5:1, крупного — 3:1. Проверять в обеих темах.
- Тёмная тема живая: проверяется `data-theme="dark"` и системная.
- Картинки с `width`/`height`, `loading="lazy"` для всего ниже первого экрана.
- `alt` описывает кадр, а не повторяет заголовок.

## 4. Как смотреть результат

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 5. Структура

| Путь | Что это |
|---|---|
| `index.html` | страница целиком |
| `assets/css/tokens.css` | цвета, размеры, тайминги. Правки начинать отсюда |
| `assets/css/app.css` | вёрстка и анимация |
| `assets/css/fonts.css` + `assets/fonts/` | Cormorant Garamond, Onest, Grand Hotel |
| `assets/js/app.js` | тема, меню, появление секций, выбор цвета, форма |
| `assets/img/` | фотографии и фоновые текстуры |
| `.claude/skills/` | 184 скилла, обязательны к применению |
| `.claude/SKILLS.md` | карта скиллов: что есть и откуда |
