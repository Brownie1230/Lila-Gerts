# Lila Gerts

Сайт мастерской: свечи и керамические фигурки ручной работы.

Одна страница, статика. Сборка не нужна, внешних запросов нет: шрифты, стили,
скрипт и изображения лежат рядом, поэтому страница открывается и без интернета.

## Посмотреть

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | страница целиком |
| `assets/css/tokens.css` | цвета, размеры, тайминги. Правки начинайте отсюда |
| `assets/css/app.css` | вёрстка и анимация |
| `assets/css/fonts.css` + `assets/fonts/` | Cormorant Garamond, Onest, Grand Hotel, SIL OFL 1.1 |
| `assets/js/app.js` | тема, меню, появление секций, выбор цвета, форма |
| `assets/img/` | фотографии и фоновые текстуры |
| `CLAUDE.md` | правила работы в репозитории |
| `.claude/skills/` | 184 скилла, обязательны к применению |
| `.claude/SKILLS.md` | карта скиллов: что есть и откуда |

## Как устроена главная

Первый экран — одна фотография во всю высоту, логотип стоит в ней. Под ним
тёмный блок с фразой о подходе, тонкая строка обещаний, центрированная метка
«Коллекция» и три плитки, затем подробные развороты по направлениям,
полноэкранный разворот с фразой, блоки о свечах и доставке, форма заказа.

Геометрия прямоугольная, теней нет: глубину держат фотографии и волосяные
линии. Капитель с разрядкой — только в меню и в метках разделов.

## Заменить перед запуском

- Фото для плитки и разворота «Фигурка по фото питомца». Места помечены
  атрибутом `data-photo-slot`: `portrait-tile`, `portrait-pair`, `portrait-hand`.
  Сейчас там стоят фоновые текстуры, настоящих снимков фигурки в репозитории нет.
- Логотип файлом. Сейчас лого собрано из двух шрифтов: «Lila» рукописным
  Grand Hotel над «GERTS» капителью Cormorant Garamond. Это замена, а не выбор:
  Grand Hotel только латиница. Когда придёт файл от заказчицы, менять
  `--font-script` в `assets/css/tokens.css` и `assets/css/fonts.css`.
- Настоящие отзывы
- Раздел «Обработка данных» показать юристу
