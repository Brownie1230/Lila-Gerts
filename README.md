# Lila Gerts

Сайт мастерской: свечи и керамические фигурки ручной работы.

Одна страница, статика. Сборка не нужна, внешних запросов нет: шрифты, стили,
скрипт и изображения лежат рядом, поэтому страница открывается и без интернета.

## Посмотреть

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | страница целиком |
| `assets/css/tokens.css` | цвета, размеры, тайминги. Правки начинайте отсюда |
| `assets/css/app.css` | вёрстка и анимация |
| `assets/css/fonts.css` + `assets/fonts/` | Cormorant Garamond, Onest, Grand Hotel, SIL OFL 1.1 |
| `assets/js/app.js` | тема, меню, появление секций, выбор цвета, форма |
| `assets/img/` | фотографии и фоновые текстуры |
