# Lila Gerts

Сайт мастерской Lila Gerts: авторские свечи и гипсовые подсвечники ручной работы.
Одна страница, сборка не нужна. Всё — шрифты, стили, скрипт, картинки — лежит рядом.

**Адрес:** https://lila-gerts.github.io/

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | вся страница: товары, тексты, формы |
| `404.html` | страница «Такой страницы нет» |
| `assets/css/tokens.css` | цвета, шрифты, размеры |
| `assets/css/app.css` | основа вёрстки |
| `assets/css/shop.css` | полоска, каталог, окно товара, корзина |
| `assets/js/app.js` | корзина, окна, фильтры, отправка заказа |
| `assets/img/catalog/` | фото товаров, по два размера на каждое |

## Как поменять сайт

Всё правится в `index.html` обычным текстовым редактором. Найти нужное место проще всего поиском
(Ctrl+F) по названию товара.

### Цена товара

У карточки два места: `data-price="2999"` (число, без пробелов) и текст
`<span class="price">2&nbsp;999&nbsp;₽</span>`. Поменяйте оба. Разметка для поисковиков
пересчитается сама.

### Добавить товар

1. Подготовьте фото в двух размерах, вертикальное 3:4, в формате webp. С ImageMagick это две
   команды:

   ```bash
   convert фото.jpg -resize 720x960^ -gravity center -extent 720x960 -quality 78 assets/img/catalog/name.webp
   convert фото.jpg -resize 360x480^ -gravity center -extent 360x480 -quality 76 assets/img/catalog/name-360.webp
   ```

2. Скопируйте любой блок `<figure class="card" …> … </figure>` и поменяйте в копии:
   - `data-sku` — уникальное имя латиницей, например `juli-lilac`;
   - `data-cat` — `candle` для свечи или `set` для набора (по нему работают фильтры);
   - `data-name`, `data-sub`, `data-price`, `data-img`;
   - по желанию `data-incl` (состав), `data-size` (размер), `data-burn` (горение) — они
     появятся в окне товара; если их нет, строки просто не покажутся;
   - у картинки `src`, `srcset` и `alt` (что на фото, словами);
   - видимые цену, название и подпись, и `aria-label` у кнопки.

Счётчики на фильтрах «Все / Свечи / Наборы» пересчитаются сами.

### Убрать товар

Удалите его блок `<figure class="card" …> … </figure>` целиком.

### Ароматы

Список в окне товара: `<select id="qv-scent">`, по строке `<option>` на аромат.

### Выбор цвета

Сейчас он есть только у штучного пиона. Цвета записаны в карточке:
`data-colors="Малиновый:#8E1F3A;Пыльная роза:#C98790;…"` — название, двоеточие, цвет, точка с
запятой. Добавьте такой атрибут другой карточке, и у неё тоже появится выбор цвета; уберите — и
выбор исчезнет.

### Доставка

Сумма считается в `assets/js/app.js`: `SHIP = 300` и `FREE_FROM = 5000`. Тексты про доставку в
`index.html` — в ленте обещаний вверху, в полосатом блоке «Бесплатная доставка», в «Условиях
покупки», в подвале и в описании страницы (`<meta name="description">`). Меняя цифры, пройдите
поиском по «300» и «5 000».

### Почта для заказов

Заказы уходят через сервис FormSubmit на lila_gerts@mail.ru. В `data-endpoint` у формы
`#order-form` стоит не сам адрес, а код из письма FormSubmit, чтобы почту не собирали спамеры:
`https://formsubmit.co/ajax/0e8514174feba3acabc7f4884c703aed`. Чтобы сменить почту, впишите вместо
кода новый адрес и активируйте форму письмом заново.

- Самый первый заказ присылает на эту почту письмо **«Activate Form»**. Кнопку в нём нужно нажать
  один раз; после этого заказы приходят сами.
- После активации FormSubmit предлагает адрес-псевдоним из случайных букв. Если вписать его
  в `data-endpoint` вместо почты, адрес не будет виден в коде страницы и спама станет меньше.
- Если отправка не удалась, сайт копирует заказ покупателю, чтобы тот прислал его в Telegram.
  Заказ не теряется.

### ИНН

Стоит в разделе «Условия покупки» (`id="terms"`), в строке «Продавец».

### Свой домен

1. Купите домен, например на reg.ru. Лучше на имя владелицы магазина.
2. В настройках DNS домена добавьте четыре записи типа **A** для `@`:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`,
   и запись **CNAME** для `www` → `lila-gerts.github.io`.
3. На GitHub: Settings → Pages → Custom domain — впишите домен и включите HTTPS.
4. В `index.html` замените `https://lila-gerts.github.io/` на новый адрес
   (строки `canonical`, `og:url`, `og:image`). Страница 404 подстроится сама.

## После правки стилей или скрипта

У ссылок на `.css` и `.js` в `index.html` стоит номер версии: `app.css?v=20251020a`. Меняя
стили или скрипт, поменяйте этот номер (например, на сегодняшнюю дату) во всех пяти строках.
Иначе телефоны покупателей могут взять новую страницу со старыми стилями из кэша, и вёрстка
развалится.

## Посмотреть у себя

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

Двойной клик по `index.html` не подойдёт: браузер не пустит шрифты со страницы, открытой как файл.

## Публикация

Сайт раздаёт GitHub Pages из ветки `main`, папка `/ (root)`. Изменения появляются на сайте
примерно через минуту после отправки в `main`.
